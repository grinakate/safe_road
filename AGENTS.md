# AGENTS.md

## Обзор
Этот репозиторий содержит многокомпонентный проект, включающий серверную часть и мобильное приложение. Серверная часть реализована на Java с использованием Maven, а мобильное приложение построено на Flutter. Проект структурирован для поддержки локальной разработки с использованием Docker и включает миграции базы данных с помощью Liquibase.

## Архитектура

### Серверная часть
- **Расположение**: `safe-road-backend-parent/`
- **Компоненты**:
  - `app-main/`: Основная логика приложения.
  - `core/`: Общая функциональность.
  - `db/`: Код, связанный с базой данных, и миграции.
  - `module-*`: Модульные функции (например, геймификация, обучение, профиль).
- **Инструмент сборки**: Maven.
- **База данных**: PostgreSQL.
- **Документация API**: Swagger доступен по адресу `http://localhost:8080/swagger-ui/index.html` (при локальном запуске).

### Мобильное приложение
- **Расположение**: `mobile/`
- **Фреймворк**: Flutter.
- **Ресурсы**: Находятся в `mobile/assets/` (например, иконки, изображения).
- **Платформо-специфичный код**:
  - Android: `mobile/android/`
  - iOS: `mobile/ios/`
  - Web: `mobile/web/`
  - Desktop: `mobile/linux/`, `mobile/macos/`, `mobile/windows/`

## Рабочие процессы разработчика

### Серверная часть
1. **Запуск локальной инфраструктуры**:
   ```shell
   docker-compose up -d
   ```
2. **Запуск миграций базы данных**:
   ```shell
   cd ./safe-road-backend-parent/db
   mvn process-resources liquibase:update@migrate-backend "-Ddb.url=jdbc:postgresql://localhost:5432/safe_road?currentSchema=safe_road" "-Ddb.username=safe_road" "-Ddb.password=safe_road" "-DskipTests=true"
   ```
3. **Остановка локальной инфраструктуры**:
   ```shell
   docker-compose down
   ```

### Мобильное приложение
- Применяются стандартные рабочие процессы Flutter:
  - **Запуск приложения**:
    ```shell
    flutter run
    ```
  - **Сборка приложения**:
    ```shell
    flutter build <platform>
    ```

## Специфические соглашения проекта

### Серверная часть
- Модульная структура для функций (`module-*` директории).
- Liquibase для миграций базы данных.
- Docker Compose для локальной инфраструктуры.

### Мобильное приложение
- Ресурсы организованы в `mobile/assets/`.
- Платформо-специфичный код разделен по соответствующим директориям (например, `android/`, `ios/`).

## Ключевые файлы и директории
- `safe-road-backend-parent/docker-compose.yaml`: Определяет локальную инфраструктуру.
- `safe-road-backend-parent/db/`: Миграции базы данных.
- `mobile/lib/`: Основной код мобильного приложения Flutter.
- `mobile/assets/`: Статические ресурсы для мобильного приложения.

## Внешние зависимости
- **Серверная часть**:
  - База данных PostgreSQL.
  - Swagger для документации API.
- **Мобильное приложение**:
  - Фреймворк Flutter.

## Заметки для AI-агентов
- Следуйте модульной структуре в серверной части при добавлении новых функций.
- Убедитесь, что ресурсы правильно размещены в `mobile/assets/` для мобильного приложения.
- Используйте предоставленную настройку Docker Compose для обеспечения согласованных локальных сред разработки.
